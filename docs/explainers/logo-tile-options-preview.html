Logo tile colour options, PET-79

The mapping originally proposed, then five candidates, each drawn under all five themes the ticket ships, at the three sizes the app paints the tile at: the access-screen lockup, the sidebar tile, and 16px for the favicon.

Each cell reports three measurements. The $ on the box and the letters against the page are held to 3:1, the WCAG floor for non-text and large graphical objects. The box against the page is held to 1.5:1, which is not a WCAG number: it is roughly where the tile stops having a visible edge. Read that one by eye and treat the figure as a hint.

The favicon is a separate case whatever you pick. frontend/src/app/icon.svg is served as a static file outside the page, so no theme value can reach it. It keeps literal hexes regardless.
